# ETL-пайплайн: витрина данных страховой компании

Сборка единой витрины данных из трёх Excel-файлов с конвертацией сумм в USD по курсу ЦБ РФ.

## Задача

Объединить данные о договорах, клиентах и убытках в одну таблицу по действующим полисам и привести все суммы к долларам США.

## Что делает пайплайн

1. **Extract:** читает три Excel-файла: договоры (3 711), клиенты (3 711) и убытки (45); курс USD/RUB запрашивает через API ЦБ РФ на вчерашнюю дату (при недоступности есть резервный источник, а если недоступны оба, пайплайн останавливается, а не подставляет курс «наугад»).
2. **Transform:**
   - оставляет только договоры со статусом «Действует» (3 315);
   - присоединяет клиентов (left join, с проверкой, что число строк не изменилось), собирает инициалы в формате «Ф. И. О.»;
   - суммирует выплаты по клиенту и присоединяет к полисам (пустые значения = 0);
   - переводит цену, страховую сумму и выплаты в USD (полисы, уже оформленные в долларах, не пересчитываются).
3. **Load:** сохраняет витрину (3 315 строк, 17 столбцов) в `insurance_datamart.xlsx` (файл создаётся при запуске и в репозиторий не включён, так как содержит данные источника) с форматированием: заголовок, зебра, фильтры, форматы чисел.

## Допущения

- Убытки в исходных данных привязаны к клиенту, а не к договору. Выплаты суммируются по `client_id` и присоединяются к полису клиента: это корректно при одном действующем полисе на клиента.
- В файле убытков нет валюты: принято, что выплата в валюте договора.
- Курс берётся на дату запуска минус один день, поэтому при повторном запуске числа в USD изменятся.
- Данные анонимизированы (ФИО в виде инициалов, номера договоров замаскированы).

## Исходные данные

Исходные файлы (`contracts.xlsx`, `clients.xlsx`, `losses.xlsx`) в репозиторий не включены и не распространяются; для запуска ноутбука поместите их рядом с ним.
