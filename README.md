# Insurance Data Mart ETL Pipeline

Практическая работа: разработка ETL-пайплайна на Python для создания единой витрины данных страховой компании из нескольких гетерогенных источников.

---

## Описание проекта

Проект объединяет разрозненные данные о клиентах, страховых полисах и убытках компании, обогащает их дополнительными признаками и конвертирует денежные суммы в доллары США по актуальному курсу валют через внешнее API.

### Источники данных:
* Данные о проданных страховых полисах (Excel).
* Данные клиентов-страхователей с анонимизированными инициалами, полом и возрастом (Excel).
* Данные об убытках компании (Excel).
* Внешний API курсов валют для конвертации сумм в USD.

### Результат:
* Сформированная и очищенная витрина данных, сохраненная в файл `insurance_datamart.xlsx`.

---

## Стек и инструменты
* **Python**, Pandas, Openpyxl
* **REST API** (интеграция данных о курсах валют)
* **Jupyter Notebook** (реализация ETL-процесса)

---

## Структура репозитория
* `insurance_etl.ipynb` — Jupyter Notebook с полным кодом ETL-пайплайна и расчетами.
* `insurance_datamart.xlsx` — итоговая витрина данных.
